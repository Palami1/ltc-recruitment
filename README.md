# LTC Recruitment System

ລະບົບຮັບສະໝັກວຽກ — Lao Telecom

## ເລີ່ມໃຊ້ງານ (ພາຍໃນເຄື່ອງ)

1. ຕິດຕັ້ງ Node.js
2. `cd server` → `npm install` → ສ້າງ `.env` ຈາກ `.env.example`
3. `cd client` → `npm install`
4. ເປີດ `start.bat` ທີ່ root

## ຄວາມປອດໄພ

- **ຢ່າ** commit ໄຟລ໌ `.env` ຫຼື `server/uploads/`
- ໃຊ້ GitHub repository ແບບ **Private** ເທົ່ານັ້ນ
